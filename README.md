# Vaishnavi Sarode — Data Analyst Portfolio

A responsive, single-page portfolio built with HTML, CSS and vanilla JavaScript. Includes gently floating skill badges and a rotating typewriter headline.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Before publishing — personalize these items
1. Replace `your.email@example.com` with your professional email address.
2. Replace the generic LinkedIn and GitHub profile URLs with your actual profile URLs.
3. Replace each `https://github.com/` project link with the corresponding repository URL.
4. Add your resume PDF as `assets/Vaishnavi_Sarode_Resume.pdf` (create the `assets` folder if needed).
5. If you want a real headshot, replace the VS monogram card in the hero with your photo.
6. Confirm project descriptions and technologies match the final state of each repository. The Myntra and Food Delivery entries are described conservatively; add further analysis only after it is completed.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `vaishnavi-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md` and the `assets` folder if used.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub Pages will provide your public website URL after deployment.

## Files
- `index.html` — page content and sections
- `style.css` — responsive visual design
- `script.js` — mobile navigation, scroll progress and reveal animations
